# TenantFlow frontend

This directory contains the Next.js application, Supabase authentication integration, organization and team authorization, customer and invoice management, Stripe Test Mode subscriptions, secure invitations, append-only audit logging, Drizzle schema and migrations, Vitest suites, and Playwright workflows.

Use the root [README](../README.md) for setup and verification. Never commit `.env.local` or `.env.test.local`, and never place database/service-role credentials in `NEXT_PUBLIC_` variables.
